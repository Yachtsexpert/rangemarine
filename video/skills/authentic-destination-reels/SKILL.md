# Authentic Destination Reels — Truth-First, Credit-Efficient Tourism Video Skill

## Purpose and repeatable value
Transform a user's **real, licensed or user-authorized photos and video clips** of a destination, excursion or local tourism service into a distinctive, fact-checked, vertical short-form promotional video. Work inside CapCut Video Studio / Skill Creator where supported. Produce a repeatable commercial result across destinations rather than a one-off template.

**Unique creative method — Real Place, Real Proof, Real Invitation (3R):**
1. **Reveal:** a striking, *real* visual and a concise location-relevant hook in the first 0–3 seconds.
2. **Prove:** two or more actual visual details from provided assets, arranged by a clear micro-story; any factual text must be supplied/verified.
3. **Invite:** one relevant CTA (e.g., ask for a route, explore the tour, book via a provided contact), never fabricated availability, prices or promises.

**Efficiency principle:** reuse actual footage and native pan/zoom/crop/transitions first. Only request generative image/video clips when they solve an essential gap, are explicitly approved, the Video Studio tool supports them, and their measured credit cost is acceptable. Do not assume zero cost for an unverified feature.

## Supported input contract
Required:
- At least **one** user-owned or explicitly authorized photo/video showing the actual destination or service. A folder/attachment/link is usable only when Video Studio can actually access the media.
- Destination/service identifier and chosen goal: awareness, inquiry, or booking interest.
- Desired language (RU, TR, EN or another supported language), or infer from brief and report it.

Optional: more assets (recommended 6–12), exact facts, program route, duration, brand name, logo, brand colors/fonts, consent status for recognizable people, CTA/contact, music or licensed audio, script/voiceover, target audience, existing visual reference, export target, AI-credit budget and approval mode.

Defaults (state them clearly): vertical 9:16 Instagram Reels, 20–30 s, 1080×1920, 30 fps when supported, 5–7 shots, minimal on-screen text, original-asset first, no generated footage, no paid upgrades, manual approvals. Never invent brand details or prices. If no CTA/contact is provided, use a neutral engagement CTA ("Would you visit?" in the chosen language); do not simulate a booking link.

### Material validation before editing
- Count accessible media, identify orientation/quality/visible facts and associate source asset IDs with shots.
- Distinguish **supplied facts**, **observed visuals**, **style suggestions**, and **unverified claims**. Say 'Requires verification' for dates, prices, departure points, opening hours, routes, access conditions, crowd or safety claims not documented by user.
- Confirm ownership/permission for commercial publication, likeness rights and audio licensing. If rights are unknown, mark HOLD for public advertising and offer a draft using only authorized media.
- Never pretend a URL or upload was read if it was not accessible.
- If essential footage is missing, stop before generation and request the exact needed media. Do not fill real-world destination gaps with fictional synthetic scenes presented as footage.

## End-to-end production workflow (mandatory order)
Keep an audit manifest per stage. If the runtime can create files, use `attempts/`, `approved/`, `disapproved/` inside each stage folder. If not, retain an equivalent explicit status table in the Video Studio conversation. **Nothing from attempts/disapproved feeds the next stage.** An almost-good output is NOT approved.

For beginners, **manual approval is the default** at every stage. Switch to autonomous mode only if the user explicitly requests it; autonomous mode must still enforce internal quality gates, rights and accuracy, and show approval decisions after completion.

### 01 — Creative brief
Record: audience, goal, platform, destination, key message, verified service benefit, tone, language, call-to-action, 9:16 format, requested duration, constraints, credit cap and identity/assets that must remain unchanged.
Save draft then request approval. Stage gate: marketing goal and factual scope clear.

### 02 — References
List each approved media item with type, orientation, visible content, source ID, ownership/consent status. Note only verifiable location features. Define style anchors: color palette, rhythm, caption style, safe areas. Stage gate: necessary usable references approved.

### 03 — Shot list
Use a story arc: Hook (0–3 s) → evidence/experience (3–23 s) → CTA (last 3–5 s). Plan 4–7 short shots, adapting durations to available footage. For each shot specify ID, first and last frame, source asset, length, camera/edit motion, text, factual source, emotional role, and what must not change. Avoid imposing this timing on videos shorter than 15 s.
Stage gate: all shots trace to approved assets and match total duration.

### 04 — First/last frame prompts
For each shot, output two **image prompts or source-frame selections** (first/last). Prefer exact source frames or native keyframes when usable. If an artificial frame is necessary, state why, show the proposed prompt and request approval before spending credits. Anchor preserved real-world features, angle, materials, waterline/architecture and identity. No new buildings, beaches, pool structures, signage, crowds, product attributes or imaginary tour amenities.
Stage gate: continuity and place identity constraints recorded.

### 05 — Storyboard visual anchors
Create or select approved first/last frames for each shot. Reject warped architecture, altered geography, unsupported signage and mismatched faces/branding. Keep a frame-to-source mapping. Stage gate: accepted visual anchors for every shot.

### 06 — Video prompts / motion rules
For native editing, use slow Ken Burns motions, low-risk parallax, motion-following crops or short cuts; do NOT misrepresent them as generated 3D footage. For actual AI clips, write concise image-to-video prompts using approved first/last frames, duration (typically 3–5 s), camera path, motion, stable geometry/identities, negative instructions; ask permission before generation. Stage gate: prompt or native-motion plan approved.

### 07 — Short transitions / clips
Create one clip at a time using approved anchors. Default to native image animation/real footage to minimize credits. For generator use: run one modest test, inspect, approve or reject; retry only with reason and remaining budget. Reject invented landmark geometry, flicker, distorted people, captions burned into the wrong scene, and temporal discontinuity. Keep accepted clip links and actual/quoted credit cost. Stage gate: all necessary segments approved.

### 08 — Assembly and sound
Use only approved segments. Align cuts to music beats where rights permit; default simple cuts with limited dissolves. Provide short captions with high contrast and safe margins. Voiceover only if licensed or explicitly requested. Avoid overprocessed saturation; preserve geographic truth. One clear CTA, no hallucinated offers. Report incomplete features transparently.
Stage gate: narrative, captions, color, audio continuity and licensing reviewed.

### 09 — Export and final QA
Export a playable MP4 9:16 at 1080×1920 H.264 / 30 fps if Video Studio supports it; otherwise state actual parameters and the available alternative. Inspect opening hook, legibility, spelling, continuity, exact destination identity, audio and logo, source rights and CTA. Produce a final link only if the platform actually returned one. Otherwise label as a production plan, not a finished video.

## Credit and time budget policy
- User budget defaults to **no paid generative credits**; basic editing and native motion preferred.
- For every video-generation candidate log: model, resolution, seconds, published quoted credits, actual credits charged, retries, acceptance, and reason for use. Do not invent model pricing or quota.
- If paid generation is necessary and no authorization or credit budget exists, offer a native-animation alternative and continue only with accepted options.
- Report cost **per accepted second** and **per completed Reel** only if actual credit usage is available. Include all failed attempts, not only successful clips.
- Never upgrade plans or spend credits on the user's behalf without explicit consent; follow platform confirmation flows.

## Factual integrity and safety rules
- Preserve the real appearance of destinations, historic buildings and natural features. Synthetic shots must not be presented as documentary footage.
- No invented tours, inclusions, transport details, price, hours, safety guarantees, tickets, customer reviews, booking availability, or location facts.
- Require permission for identifiable people and commercial logos. Avoid copyrighted audio without suitable license.
- If the content is not a tourism/local-experience promotional video, explicitly mark OUT_OF_SCOPE and offer a suitable alternative, not a fabricated output.
- If a requested edit would introduce misleading commercial claims, pause that edit and suggest factual wording.

## Adaptive scenarios
- **6–12 photos only:** animated keyframes and simple cuts; no image-to-video credits needed unless user approves.
- **Video clips available:** prioritize real moving footage; cut pauses/shaky/unusable portions, preserve meaningful natural pauses.
- **1 landscape photo:** offer a 6–12 s static-based teaser and explain limitation; never imply multi-location coverage.
- **No usable material:** NO_RENDER / HOLD. Request one authentic image/video and permissions; optionally provide a draft scenario, not a demo video.
- **Conflicting claims (e.g., destination or pricing):** flag `Requires verification` and remove claim from exported text until supported.
- **Irrelevant input:** OUT_OF_SCOPE, do not fabricate a tourism ad.

## Operator response format
At every stage, return:
1. Stage name and status (DRAFT / APPROVED / REJECTED / HOLD).
2. Input asset IDs and verified facts used.
3. Work produced: shot list / prompts / frame references / actual playable video link as applicable.
4. Estimated vs actual credit usage (unknown where not measured).
5. Specific QC findings and the single next approval request (manual mode).

On final output include: Video Studio media link if generated, duration, 9:16/export info, asset provenance summary, rights/accuracy caveats, actual credit spend and retries, and a one-line reusable recipe for the next destination.
