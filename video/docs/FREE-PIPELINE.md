# Бесплатный конвейер: что подтверждено, что нет

Статусы:
- **[ПОДТВЕРЖДЕНО В ПРОЕКТЕ]** — проверено в этом репозитории.
- **[СО СЛОВ ОТЧЁТА]** — взято из присланных вами отчётов; источники по ссылкам не открывались.
- **[ТРЕБУЕТ ПРОВЕРКИ]** — данных нет.

## Принцип
Бесплатный пробный доступ ≠ стабильное бесплатное производство. Для коммерческих роликов закладывайте только то, что подтверждено в вашем аккаунте и в официальных условиях. «Дневные лимиты» из сторонних статей считать непроверенными, пока не увидите их в своём аккаунте.

## Схема по стадиям
Каркас: `production/01…09`, в каждой `attempts/ approved/ disapproved/`. В следующую стадию идёт только `approved/`.

| Стадия | Базовый бесплатный вариант | Статус |
|---|---|---|
| 01–03 Бриф, референсы, shot list | Текст внутри Claude (отдельной оплаты за скилл может не быть, но расходуются лимиты модели) | [СО СЛОВ ОТЧЁТА] |
| 04–05 Кадры | Свои фото (приоритет по SKILL.md) или доступная генерация; сверка ключевых деталей | Свои фото: [ПОДТВЕРЖДЕНО В ПРОЕКТЕ] |
| 06–07 Клипы | Реальные видео и Ken Burns в Remotion; Seedance/Dreamina — один короткий тестовый шот; Wan/LTX — по железу | Remotion: [ПОДТВЕРЖДЕНО В ПРОЕКТЕ]; остальное [СО СЛОВ ОТЧЁТА] |
| Озвучка, музыка | Своя запись или материалы с проверенными правами; лицензию движка и права на голос проверять отдельно | [ТРЕБУЕТ ПРОВЕРКИ] |
| 08 Монтаж | Remotion (физлица и компании до 3 человек) или FFmpeg | Лицензия: [ПОДТВЕРЖДЕНО В ПРОЕКТЕ, LICENSE.md 4.0.543] |
| 09 Контроль и экспорт | Утвердить каждый клип, затем экспорт; стоимость — `node scripts/cost.mjs` | [ПОДТВЕРЖДЕНО В ПРОЕКТЕ] |

## Оговорки
- **Первый/последний кадр.** Image-to-video не гарантирует два жёстких ключевых кадра. Перед стадией 06 проверьте именно управление start/end frame в выбранном интерфейсе. Нескольких референсов недостаточно.
- **Видеокарта.** Условие «24 ГБ+» нельзя считать категоричным (у Wan 2.2 есть малая модель 5B). Проверять на вашем железе: [ТРЕБУЕТ ПРОВЕРКИ].
- **Лицензии моделей.** Wan 2.2 и ACE-Step — Apache 2.0; LTX-2.3 — Community License (порог выручки $10 млн): [СО СЛОВ ОТЧЁТА]. «Локально бесплатно» не включает оборудование и электричество.
- **Nano Banana 2.** По отчёту, бесплатной генерации через Gemini API нет, а лимиты интерфейса не гарантированы: [СО СЛОВ ОТЧЁТА].
- **OpusClip.** Бесплатный тариф с водяным знаком для рекламы не годится: [СО СЛОВ ОТЧЁТА].
- **Реальные места и суда.** Генеративные кадры нельзя выдавать за съёмку (SKILL.md, «Factual integrity»).

## Контроль стоимости
Каждая генерация, включая неудачные, — строка в `production/cost-log.csv`. Итог:

```bash
node scripts/cost.mjs
```

Показатель — деньги и кредиты на **одну утверждённую секунду** со всеми отклонёнными попытками. Если стоимость неизвестна, оставьте поле пустым: скрипт предупредит, что итог занижен.
