# Parser YouTube — скрипт для Google Таблиц

Меню **Parser YouTube** в таблице открывает сайдбар справа со всеми фильтрами поиска YouTube и большой кнопкой «Поиск». Найденные ролики построчно ложатся в ячейки листа.

## Что попадает в таблицу

| Колонка | Что внутри |
|---|---|
| № | Порядковый номер |
| Ссылка | `https://www.youtube.com/watch?v=…` |
| Дата публикации | Настоящая дата, по ней работает сортировка |
| Превью | Картинка в ячейке через `=IMAGE(...)` |
| Название | Заголовок ролика |
| Описание | Полный текст описания |
| Просмотры / Лайки / Комментарии | Числами, с разделителями разрядов |
| Длительность / Секунд | `12:34` и то же число секунд для сортировки |
| Канал / Ссылка на канал / ID канала | Автор ролика |
| Качество | HD или SD |
| Субтитры | Есть / Нет |
| Лицензия | Стандартная или Creative Commons |
| Формат | 2D или 3D |
| Встраивание | Разрешено / Запрещено |
| Категория | Название категории YouTube |
| Язык | Язык озвучки или описания |
| Теги | Все теги ролика через запятую |
| Статус | public / unlisted |
| Трансляция | Обычное видео, идёт эфир, запланирована, завершённая |
| ID видео | Идентификатор для сверки |

## Фильтры в сайдбаре

Запрос, количество роликов (до 500), сортировка, даты публикации «после» и «до», длительность, качество, субтитры, лицензия, 2D/3D, трансляции, встраивание, доступность вне YouTube, язык, регион, безопасный поиск, ID канала, поиск по координатам с радиусом, имя листа и очистка листа перед записью.

## Установка — 3 минуты

1. Откройте нужную Google Таблицу → **Расширения → Apps Script**.
2. В файле `Код.gs` удалите всё и вставьте содержимое [`Code.gs`](Code.gs).
3. Слева нажмите **+ → HTML**, назовите файл ровно `Sidebar` (без расширения, оно добавится само) и вставьте содержимое [`Sidebar.html`](Sidebar.html).
4. Слева в разделе **Службы** нажмите **+**, выберите **YouTube Data API v3**, идентификатор оставьте `YouTube`, нажмите «Добавить».
5. Сохраните проект (Ctrl+S) и вернитесь в таблицу — обновите страницу.

В меню появится **Parser YouTube**. При первом запуске Google попросит разрешение на доступ к таблице и к YouTube — это ваш собственный аккаунт, тот же, под которым вы смотрите YouTube.

### Вариант для тех, кто работает через clasp

```bash
npm install -g @google/clasp
clasp login
cd apps-script
clasp create --type sheets --title "Parser YouTube"
clasp push
```

`appsscript.json` уже содержит подключённый YouTube Data API v3 и нужные разрешения, шаг 4 в этом случае не нужен.

## Квота

Один поиск стоит примерно 100 единиц квоты YouTube API за каждые 50 роликов плюс немного на метаданные. Сайдбар после каждого поиска показывает, сколько потрачено. Бесплатный дневной лимит — 10 000 единиц, то есть около сотни поисков по 50 роликов в день.

Если упрётесь в квоту, подключите к скрипту свой проект Google Cloud: **Настройки проекта → Проект Google Cloud Platform → Изменить проект**, и там же в Cloud Console включите YouTube Data API v3.

## Частые вопросы

**«YouTube is not defined»** — не выполнен шаг 4, служба YouTube Data API v3 не подключена.

**Превью не видно** — увеличьте высоту строки; скрипт ставит 80 пикселей, но если лист был отформатирован раньше, Google может сохранить старую высоту.

**Вместо картинки `#ERROR!` в колонке «Превью»** — не совпал разделитель аргументов в формуле. В русской локали `IMAGE` требует точку с запятой, в английской — запятую. Скрипт определяет локаль таблицы сам и по умолчанию ставит точку с запятой; если у вас редкая локаль, допишите её код в список `COMMA_LOCALES` в начале `Code.gs`.

**Нашлось меньше, чем просили** — YouTube отдаёт ограниченную выдачу по узким фильтрам. Ослабьте фильтры или уберите даты.
