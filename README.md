# Range Marine / OK-Boats — лендинг

Одностраничный сайт компании: подбор, проверка, поставка и оформление
катеров, яхт и моторов из Европы в Россию.

## Файлы

- `index.html` — вся страница: стили, разметка и скрипт фона в одном файле,
  без внешних зависимостей кроме Google Fonts.

## Перед публикацией

В `index.html` найти комментарии `ЗАМЕНИТЬ` и подставить реальные контакты:

- `https://wa.me/70000000000` — номер WhatsApp (в трёх местах);
- `https://t.me/rangemarine` — ник в Telegram (в трёх местах).

## Дизайн

Направление — бумага морской карты: изобаты и промеры глубин на фоне героя,
адмиралтейская маджента как единственный акцент.

- Шрифты: Prata (заголовки), Golos Text (текст), IBM Plex Mono (данные и метки).
- Светлая и тёмная темы через токены на `:root`, включая состояние «системная тема».
- Фон героя рисуется на Canvas и перерисовывается при смене темы и размера окна.
