# Range Marine / OK-Boats — лендинг

Одностраничный сайт компании: подбор, проверка, поставка и оформление
катеров, яхт и моторов из Европы в Россию.

## Файлы

- `index.html` — самостоятельная страница целиком (стили, разметка, скрипт
  фона в одном файле). Открывается как есть, годится под отдельный домен.
- `webasyst-embed.html` — та же страница как блок для вставки в страницу
  Webasyst. Весь CSS заизолирован внутри `.rm-lp`, классы с префиксом `rm-`,
  теги `header`/`footer`/`article` заменены на `div`.
- `embed/head.html`, `embed/tail.html` — стили и скрипт embed-версии.
- `build-embed.py` — пересобирает `webasyst-embed.html` из `index.html`.

## Вставка в Webasyst

1. Приложение «Сайт» → нужная страница → переключить редактор в режим HTML.
2. Вставить содержимое `webasyst-embed.html` целиком.
3. Сохранить и открыть страницу.

Чего ждать:

- Блок не влияет на остальной сайт: все правила начинаются с `.rm-lp`.
- Шрифты подключаются через `@import` внутри `<style>`. Если редактор вырежет
  `@import`, добавьте в шаблон темы (`header.html`) обычный `<link>` на тот же
  адрес Google Fonts — вёрстка не сломается, просто подставятся системные шрифты.
- Если редактор вырежет `<script>`, пропадёт только рисованный фон в шапке.
  Всё остальное — чистый CSS и работает без JavaScript.
- Чтобы блок шёл во всю ширину экрана, раскомментируйте в начале `<style>`
  строку `width:100vw; margin-left:calc(50% - 50vw);`.

После правок в `index.html` пересоберите embed:

```
python3 build-embed.py
```

## Фотографии

В вёрстке четыре слота. Пока фото нет, слот выглядит как аккуратная плашка
с подписью; как только внутрь `<figure>` попадает `<img>`, подпись исчезает,
а широкий кадр раскрывается с 40:9 до 21:9.

| Слот | Где | Размер |
|---|---|---|
| Широкий кадр | сразу под первым экраном | 2400×1030 |
| Катера и яхты | блок «Не только корпуса» | 900×675 |
| Подвесные моторы | блок «Не только корпуса» | 900×675 |
| Дизель и репауэринг | блок «Не только корпуса» | 900×675 |

Вставка — одна строка внутрь `<figure>`, первой:

```html
<figure class="shot shot--wide">
  <img src="/wa-data/public/site/photo.jpg" alt="Катер на ходу">
  <span class="shot__label">Фото: катер на ходу · 2400×1030</span>
</figure>
```

В embed-версии классы те же с префиксом: `rm-shot`, `rm-shot--wide`,
`rm-lane__shot`, `rm-shot__label`.

## Дизайн

Направление — бумага морской карты: изобаты и промеры глубин на фоне первого
экрана, адмиралтейская маджента как единственный акцент.

- Шрифты: Prata (заголовки), Golos Text (текст), IBM Plex Mono (данные и метки).
- `index.html` — светлая и тёмная темы через токены, включая «системную тему».
  `webasyst-embed.html` — только светлая, чтобы блок совпадал с темой сайта.
- Фон первого экрана рисуется на Canvas, перерисовывается при смене размера.
