# Parser YouTube

Локальная страница для поиска роликов на YouTube: слева таблица результатов, справа сайдбар с фильтрами и большая кнопка «Поиск». Вход — через свой Google-аккаунт (тот же, под которым вы заходите на YouTube).

## Что собирается по каждому ролику

№ · ссылка · дата публикации · превью (картинкой) · название · описание · просмотры · лайки · комментарии · длительность · канал · качество · субтитры · теги.

Результат можно скачать в CSV или скопировать в буфер и вставить прямо в Google Таблицу.

## Запуск

```bash
cd youtube-parser
python3 -m http.server 8000
```

Откройте http://localhost:8000

Файл нельзя открывать двойным кликом (`file://`) — вход через Google работает только по `http://localhost` или `https`.

## Настройка входа (один раз)

1. Откройте [Google Cloud Console](https://console.cloud.google.com/) и создайте проект.
2. В разделе **APIs & Services → Library** включите **YouTube Data API v3**.
3. В **OAuth consent screen** заполните базовые поля и добавьте себя в Test users.
4. В **Credentials → Create credentials → OAuth client ID** выберите тип **Web application** и в **Authorized JavaScript origins** добавьте `http://localhost:8000`.
5. Скопируйте Client ID и вставьте его в жёлтую плашку на странице — он сохранится в браузере.

После этого нажмите «Войти через Google» и подтвердите доступ на чтение YouTube.

## Ограничения квоты

Один поиск тратит примерно 100 единиц квоты YouTube API + 1 единица на каждые 50 роликов за метаданными. Бесплатный лимит — 10 000 единиц в сутки, то есть около 90–100 поисков в день.
